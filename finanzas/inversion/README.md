# Agente de Inversión

Versión portable del agente **/inversión**.

Contiene el prompt maestro, metodología y plantilla de tesis. Está diseñado para reutilizar la misma metodología en ChatGPT, OpenCode, Claude Code u otros agentes.

## Componentes

- agent.md — comportamiento del agente.
- skill.md — flujo operativo de /inversión.
- templates/investment-thesis.md — memoria estructurada de una tesis.

## GPT de ChatGPT

El mismo contenido puede copiarse a las Instructions de un GPT personalizado llamado **Inversión**.
