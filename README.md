# Cursos

Cursos prácticos creados para aprender y mejorar habilidades mediante teoría breve, ejercicios y práctica deliberada.

## Cursos

### Comunicación interpersonal

Curso práctico para mejorar la comunicación **sin intentar convertirse en otra persona ni buscar carisma**.

Incluye 13 módulos, 130 ejercicios y recursos gratuitos:

1. Diagnóstico de la comunicación
2. Dicción y vocalización
3. Voz
4. Pausas y ritmo
5. Estructura del mensaje
6. Storytelling
7. Escucha activa
8. Conversación y small talk
9. Asertividad
10. Conversaciones difíciles
11. Hablar en público
12. Lenguaje corporal
13. Práctica deliberada

Cada módulo combina ejercicios básicos y avanzados. La evaluación se apoya especialmente en la práctica y en grabaciones para poder observar la propia evolución.
